# INC-2093: Pharmacy orders not reaching the pharmacy

**Reported by:** Pharmacy Informatics
**Symptom:** After the new EHR went live, medication orders were missing from the pharmacy verification queue. The EHR sends **RDE^O11** messages to port 6681; nothing was storing them.

## Analysis
- **ORC.1** (order control) says what to do: NW new, DC discontinue, CA cancel, XO change, HD hold.
- **ORC.2** placer order (EHR) and **ORC.3** filler order (pharmacy).
- **RXE.2** drug as **NDC** code + name; **RXE.3/RXE.5** dose and unit; **RXE.1.2** frequency; **RXE.10** dispense quantity; **RXR.1** route.
- Later messages (DC, CA, XO, resends) refer to the same order, so the table must keep **one row per order**, matched on **ORC.2 + PID.3**.
- Missing order number or MRN must stop the message: an order that can't be matched could never be discontinued.

## Fix
- Table `HL7_PharmacyOrders` with `UNIQUE (placer_order, mrn)`.
- Channel `INC-2093 RDE Pharmacy Orders` (TCP/MLLP 6681):
  - Filter: MSH.9.1 = RDE **and** MSH.9.2 = O11.
  - Transformer: reads order, patient, drug, dose, route, provider; converts ORC.9 to ISO date; maps ORC.1 to a status; throws on missing ORC.2 or PID.3.
  - Destination: `UPDATE ... WHERE placer_order AND mrn`, then `IF @@ROWCOUNT = 0 INSERT` (upsert, idempotent on resends).

## Troubleshooting during the build
- First test returned `MSA|AR` (filtered): the second filter rule read `MSH.11` / `MSH.9.1` instead of `MSH.9.2`. Fixed and redeployed; messages returned `MSA|AA`.
- **XO dose not updated:** after the change orders, ORD5605 and ORD5619 showed `order_control = XO` but still had the old dose (50 mcg, 500 mg). The UPDATE only set order control, status and message ID. Added dose, unit, frequency, route, dispense quantity, filler order and location to the `SET` list, redeployed and resent the two XO messages.

## Verification
| Test | Result |
|---|---|
| 46 new orders (NW), 20 drugs, PO/IV/SC routes | 46 rows, status `active`, ACK `AA` |
| 10 follow-ups: 5 DC, 3 CA, 2 XO on existing orders | Still **46 rows** (no duplicates) |
| Status after follow-ups | active 38 · discontinued 5 · cancelled 3 |
| XO dose change, after the fix | ORD5605 50 → **100 mcg**, ORD5619 500 → **1000 mg** |
